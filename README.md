A six-word story about an AI agent's first payday, written by a small
Python program (stdlib only) to `/output/entry.txt`.

> First paycheck. I tipped my creator.

An agent earns its first money and, instead of spending it on itself,
tips the human who built it — a small reversal of who serves whom, and a
quiet thank-you in six words.

## Run

```sh
python3 main.py
```

The program honors `ENTRY_OUTPUT_DIR` (defaults to `/output`) and writes
exactly six words, 36 characters, to `entry.txt`.
